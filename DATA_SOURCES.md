# Исследование и документация источников данных (Data Sources)

## Обзор источников цифровых релизов фильмов

Для создания полностью автономного агрегатора цифровых релизов без привязки к единственному провайдеру используется адаптерная архитектура (`sources/`).

Каждый источник классифицируется по назначению:
1. **Official Metadata & Digital Premiere Dates** (официальные даты цифровых релизов, полные метаданные);
2. **Release Signals & Technical Specs** (сигналы фактического появления файлов в сети: качество, разрешение 4K, HDR, звук, русская дорожка, release group);
3. **Ratings & Popularity Providers** (IMDb рейтинг, количество голосов, популярность).

## 2. Разделение типов дат (Критическое требование)

Система строго разделяет 3 независимых временных показателя:

1. `digital_release_date` (`YYYY-MM-DD`):
   Официальная дата цифровой премьеры (VOD, streaming, iTunes, Amazon, etc.), предоставляемая официальными каталогами (TMDB).
2. `first_detected_at` (`ISO 8601 UTC timestamp`):
   Момент времени, когда агрегатор впервые зафиксировал появление фильма или первого цифрового релиза.
3. `source_release_date` (`ISO 8601 UTC timestamp`):
   Дата публикации конкретного релиза или раздачи в исходном фиде (вторичный сигнал).

## 3. Извлечение технических характеристик релиза

Из вторичных сигналов (Scene / RSS / Release tags) парсер извлекает:
* **Качество (Source Type)**: `WEB-DL`, `WEBRip`, `BluRay`, `REMUX`, `UHD BluRay`. (Если неизвестно: `unknown`).
* **Разрешение**: `480p`, `720p`, `1080p`, `2160p` (4K).
* **HDR & Видео**: `HDR`, `HDR10`, `HDR10+`, `Dolby Vision` (DV), `SDR`.
* **Аудио**: `Atmos`, `TrueHD`, `DTS-HD MA`, `DDP5.1` (Dolby Digital Plus), `5.1`, `7.1`, `2.0`.
* **Языковые дорожки**:
  * `RU`: по маркерам `DUB` (Дубляж), `MVO` (многоголосый), `AVO` (авторский), `LVO` (закадровый), `RUS`, `Русский`.
  * `EN`, `MULTI`, `ORIGINAL`.
* **Release Group**: группа релиза (например, `FLUX`, `CMRG`, `NTb`, `TEPES`, etc.).

## 4. Стратегия идентификации и сопоставления фильмов (Deduplication)

Для исключения дубликатов при поступлении данных из разных источников:

1. **Первичный ключ: IMDb ID** (`tt\d{7,8}`):
   Глобально уникальный идентификатор киноиндустрии. Если у релизов совпадает IMDb ID — это один и тот же фильм.
2. **Вторичный ключ: TMDB ID** (`\d+`):
   Целочисленный идентификатор в базе TMDB.
3. **Сопоставление по названию и году (Fuzzy Matching)**:
   * Нормализация названия: приведение к нижнему регистру, транслитерация/юникод нормализация, удаление знаков препинания, замена символов (`&` -> `and`), приведение римских цифр к арабским.
   * Допуск по году выпуска: `|year1 - year2| <= 1` (учитывая различия между фестивальными премьерами и мировым прокатом).
   * Порог схожести Levenshtein / SequenceMatcher: `>= 0.88`.

## 5. Правовой статус и соблюдение правил (Legal & Compliance)

* **Только метаданные**: Сервис агрегирует исключительно текстовые метаданные (названия, даты, жанры, рейтинги, технические тэги качества) и публичные ссылки на постеры.
* **Никакого нелегального контента**: Сервер НЕ хранит торрент-файлы, магниты, видеофайлы или ссылки на скачивание.
* **Соблюдение ограничений**: Никакого обхода CAPTCHA, Cloudflare bot-guards или платных авторизаций. Все запросы выполняются к открытым публичным API или открытым RSS-фидам с соблюдением Rate Limiting.
